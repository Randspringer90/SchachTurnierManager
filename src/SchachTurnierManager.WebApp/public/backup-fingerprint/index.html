Backup-Prüfsumme

Berechne SHA-256 für eine selbst ausgewählte Datei oder vergleiche sie mit einem separat erhaltenen Wert. Maximal 5 MiB. Die Dateibytes verlassen diese Seite nicht.

Eine passende Prüfsumme beweist keine vertrauenswürdige Herkunft und keine Wiederherstellbarkeit. Schon andere Leerzeichen, Zeilenumbrüche oder ein BOM ändern den Wert. Es wird nichts importiert, hochgeladen oder gespeichert.

Nur 64 hexadezimale Zeichen, ohne Dateinamen oder Präfix. Keine zusätzlichen Zeichen innerhalb des Werts.
