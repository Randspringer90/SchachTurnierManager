Fehlende oder ungewertete Quellwerte werden nicht als Löschvorschlag interpretiert. Bei widersprüchlichen FIDE-IDs wird kein Ratingvorschlag angezeigt. Namenabweichungen erfordern eine eigene Identitätsprüfung. Abfragefehler bleiben sichtbar; andere Profile können trotzdem ausgewertet werden.

Der bestehende Server kann FIDE kontaktieren. Es wird kein neuer Provider aktiviert. Quellabrufzeiten garantieren keine aktuellen Wertungszahlen. Das geladene Turnier kann sich zwischenzeitlich ändern; es wird weder gesperrt noch automatisch aktualisiert.

Nur für das vertrauenswürdige Operatornetz: Die vorhandenen API-Endpunkte liefern weitere private Turnierdaten. Diese Oberfläche ist keine Zugriffskontrolle und kein öffentliches Zuschauerportal. Keine dauerhafte Speicherung, keine Hintergrundabfragen ohne Start und keine neuen Fenster.
