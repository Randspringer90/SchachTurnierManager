Zur Turnierverwaltung

Verbindung zum Turnierrechner prüfen

Diese Prüfung fragt nur den bestehenden Health-Endpunkt dieser Anwendung ab. Sie startet keine Dienste, ändert keine Daten, löscht keine Caches und prüft keine fremden Server.

Pro Klick wird maximal eine Anfrage an /api/health gestellt. Die Frist umfasst auch das Lesen der Antwort. Es gibt kein automatisches Polling oder Weiterleiten auf eine andere Adresse.

Eine empfangene Healthantwort belegt weder erfolgreiche Datenbankschreibvorgänge noch Internetzugang. Datenbankpfade, Protokollverzeichnisse und technische Antwortinhalte werden nicht angezeigt. Im separaten Vite-Entwicklungsbetrieb ist ein passendes Same-Origin-API-Routing erforderlich.
