    Was das Ergebnis nicht beweist

    Eine sichtbare Schnittstelle kann bei ihrer Benutzung durch Richtlinien oder Laufzeitfehler scheitern. Der Check führt weder einen Dateiimport noch SHA-256 oder eine Service-Worker-Registrierung aus. Er prüft nicht, ob die PWA installiert ist, Daten dauerhaft gespeichert werden, das Backend erreichbar ist oder alle Programmfunktionen vorhanden sind.

    Bei fehlendem sicherem Kontext können manche Funktionen eingeschränkt sein. Nutze eine ordnungsgemäß eingerichtete HTTPS-Adresse oder die Anwendung direkt am Turnierrechner über localhost. Sicherheitsrichtlinien oder Zertifikatsprüfungen nicht abschalten.
